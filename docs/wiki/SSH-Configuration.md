# 会话管理与远程连接实操手册 (SSH & Remote Configuration)

Velowork 提供工业级、多协议的资产与远程会话管理体系。本手册将详细指导您如何组织管理会话目录树、配置高安全性 SSH 认证、设置跳板机穿透内网、连接串口/Telnet 设备，以及利用底层会话引擎实现连接保活与断线重连。

---

## 1. 会话目录树与组织管理 (Session Tree & Hierarchy)

位于左侧面板（按 `Cmd+1` / `Alt+1` 聚焦）的**会话管理器**支持无限级目录树组织：

### 1.1 目录与分组操作
- **新建文件夹**：点击会话栏顶部的“新建文件夹”图标，输入目录名（如 `华东数据中心/Kubernetes集群`）；
- **拖拽重组**：鼠标按住任意会话或文件夹，可直接拖入其他目录完成归类；
- **视觉标签与颜色标记**：右键点击会话或文件夹选择“设置标记颜色”，支持指定主题强调色，便于在大规模主机列表中瞬时定位核心生产节点；
- **全文检索**：在会话树顶部的搜索框输入 IP、别名或标签，即时对全量资产进行层级过滤与高亮。

## 2. SSH 远程会话详细配置 (SSH Configuration)

按下 `Cmd+N` / `Ctrl+N` 唤起「新建/编辑会话」弹窗。整个配置划分为以下核心板块：

### 2.1 基础设置 (Basic)
- **会话名称 (Name)**：识别标识（如 `Prod-API-Gateway-01`）；
- **主机 (Host)**：服务器 IPv4 / IPv6 地址或解析域名；
- **端口 (Port)**：默认为 `22`；
- **用户名 (Username)**：远程系统登录用户名（如 `root`、`deploy`、`ubuntu`）。

### 2.2 身份认证模式 (Authentication)
Velowork 支持多种高标准安全认证，凭据统一受系统密钥环（Keyring）与 AES-256-GCM 保护：

1. **密码认证 (Password)**：
   - 填写登录密码；密码将安全加密，绝不会在 SQLite 数据库或配置文件中以明文裸存。
2. **私钥认证 (Private Key - 推荐)**：
   - 支持格式：`id_rsa`、`id_ed25519`、PEM、PKCS#8 及 OpenSSH 原生私钥格式；
   - 点击文件选择器选取本地私钥路径；
   - **私钥口令 (Passphrase)**：若私钥设置了加密密码，填入后将自动缓存至系统凭据库，后续连接无需反复输入。
3. **键盘交互认证 (Keyboard-Interactive / 2FA / MFA)**：
   - 适用于开启了 Google Authenticator、动态短信验证码或 Radius 认证的堡垒机环境。连接时将自动弹出交互式质询输入框。

### 2.3 跳板机与堡垒机内网穿透 (ProxyJump)
当目标主机部署于内部隔离网段，需通过公网跳板机（Bastion Host）转发访问时：

```text
[本地客户端 Velowork] ---- SSH ----> [跳板机 / 堡垒机 Bastion] ---- SSH ----> [内网隔离目标服务器]
```

- **配置步骤**：
  1. 在弹窗中切换至 **网络代理 (Proxy)** 分页；
  2. 代理类型选择 **跳板机会话 (Jump Session)**；
  3. 在下拉列表中直接选取已经配置好的跳板机会话（系统将自动复用该跳板机的认证凭据与网络通道）；
  4. 支持多跳级联（A -> B -> C 穿透多重隔离网段）。

### 2.4 网络代理模式 (SOCKS5 / HTTP CONNECT)
若本地环境需通过特定代理软件出网：
- 在 **网络代理** 中选择 `SOCKS5` 或 `HTTP`；
- 填入代理服务 IP（如 `127.0.0.1`）与端口（如 `7890` / `1080`）；
- 可选填代理认证账号密码。

### 2.5 高级参数与保活机制 (Advanced & Keepalive)
- **保活探测间隔 (Keepalive Interval)**：默认每隔 30 秒发送一次空包探测，防止中间防火墙或 NAT 路由器静默切断空闲连接；
- **最大探测重试 (Max Retries)**：连续探测失败超过设定次数（默认 3 次）时判定连接中断，并触发重连机制；
- **空闲超时 (Idle Timeout)**：指定时间内无键盘与数据活动时自动断开，增强终端安全性。

## 3. 工业串口与多协议支持 (Serial Port & Telnet)

Velowork 不仅支持 SSH，还深度集成了物联网/嵌入式/网络工程常用的物理与网络协议：

### 3.1 工业串口连接 (Serial Port / UART / RS-232)
适用于交换机 Console 口调试、树莓派/单片机嵌入式开发：
1. 新建会话时，连接类型选择 **串口 (Serial)**；
2. **设备端口**：系统会自动扫描并列出本机已识别的物理与 USB 串口设备（如 Linux 下 `/dev/ttyUSB0`、Windows 下 `COM3`、macOS 下 `/dev/cu.usbserial-*`）；
3. **波特率 (Baud Rate)**：提供标准波特率下拉（如 `9600`、`19200`、`115200`、`921600` 等）；
4. **数据位 / 停止位 / 奇偶校验**：支持 `8-N-1`、`7-E-1` 等工业标准配比。

### 3.2 Telnet 协议连接
适用于传统网络路由器、工业网关与老旧远程主机的管理与调试：
- 连接类型选择 **Telnet**，输入目标 IP 与端口（默认 `23`），一键建立明文/调试终端通道。

### 3.3 X11 远程图形转发 (X11 Graphics Forwarding)
- 在 SSH 会话的 **高级选项** 中开启 **X11 转发 (Enable X11 Forwarding)**；
- 当连接至配置了 X11 的 Linux 服务器并在终端启动图形程序（如 `xclock`、`gedit`、`wireshark`）时，远程 GUI 窗口将通过安全 SSH 加密隧道直接投射并在本地桌面上自然渲染。

## 4. 会话持久化引擎与零中断重连 (Session Persistence)

针对移动办公频繁切网（如 Wi-Fi 切换、合盖休眠、蜂窝网络闪断）痛点，Velowork 引入了多引擎驱动的会话保活体系：

### 4.1 会话引擎选型 (Session Engine)
在 **设置 -> 终端 -> 会话引擎 (Session Backend)** 中可选择：
- **`dtach`（默认推荐）**：极轻量、零额外侵入的底层 TTY 脱机保活工具，在远端断网时进程持续在后台运行；
- **`tmux`**：成熟的终端复用器，支持复杂窗口与持久化会话树；
- **`screen`**：传统 Unix 标准会话保活工具；
- **`WSL`**：针对 Windows 平台 WSL 发行版的透明环境隔离与持久化支持。

### 4.2 意外断线自动恢复
- 当因网络抖动连接中断时，终端顶部将居中浮出优雅的断线提示胶囊，并自动开启倒计时重连；
- 重新连通后，Velowork 将自动 attach 回远端运行中的会话，您正在执行的长耗时编译、日志 tail 或 vim 编辑内容毫发无损。

### 4.3 快速克隆会话与通道复用
- **在新标签页中克隆当前会话**：按下 `Cmd+Alt+S` / `Ctrl+Alt+S`，立即以相同配置打开一个独立的新连接；
- **复制现有 SSH 通道 (Duplicate Channel)**：按下 `Cmd+Alt+C` / `Ctrl+Alt+C`，复用已建立的 SSH 底层加密连接快速开启一个新 Shell，无需重新走握手认证过程。

## 5. 配置导入、导出与编辑防丢失 (Import & Safety)

### 5.1 批量导入外部资产
- 点击菜单 **文件 -> 导入会话**（或快捷键 `Cmd+Shift+I` / `Ctrl+Shift+I`）；
- 支持直接解析并导入以下格式：
  - 本机 `~/.ssh/config` 配置文件与关联私钥；
  - Xshell 导出的会话结构；
  - MobaXterm 与 FinalShell 会话导出文件。

### 5.2 全应用未保存修改二次确认保护 (`soft_close`)
- 在新建或编辑会话时，如果您输入了主机信息尚未保存，意外按下 `Esc` 或点击遮罩层外部时，系统会自动拦截并弹出“存在未保存的修改”确认对话框，彻底杜绝误触导致的心血丢失。
