# Velowork 官方实操手册与技术文档中心

欢迎查阅 **Velowork** 官方操作手册！

Velowork 是一款专为开发者与系统管理员打造的**高性能、跨平台原生终端复用器与远程会话管理工作站**。基于 Rust 与 Zed 编辑器的 GPU 加速 UI 框架（GPUI）纯原生构建，具备亚毫秒级的输入响应、120 FPS 丝滑动画、极致的内存控制以及全方位的工业级连接与运维能力。

## 🚀 角色推荐阅读路线

- **日常开发 / 本地使用者**：
  先读 [快速入门指南](Getting-Started) 掌握分屏与快捷键，再读 [终端进阶与 AI 助手](Terminal-and-AI) 体验 `Ctrl+I` 内联命令生成与截图理解。
- **Linux 运维 / SRE 工程师**：
  推荐通读 [会话管理实操手册](SSH-Configuration)、[端口转发实操手册](SSH-Tunnels) 与 [服务守护实操手册](Services-and-Monitoring)，掌控多跳堡垒机与容器服务状态。
- **自动化操作与脚本爱好者**：
  深入阅读 [快捷指令实操手册](Quick-Commands) 掌握 `${VAR}` / `{{变量}}` 占位符模态参数替换与目标窗格投递机制。
- **跨设备多端协同用户**：
  参考 [云端同步实操手册](Cloud-Sync) 搭建基于 MinIO 或 WebDAV 的端到端加密同步网络。
