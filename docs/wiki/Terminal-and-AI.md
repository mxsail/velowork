# 终端进阶与 AI 助手实操手册 (Terminal & AI Assistant)

Velowork 将 GPU 原生硬件加速终端与新一代 AI 大模型能力深度融合。本手册详细介绍弱网输入零延迟、智能链接识别等终端进阶特性，以及如何配置大模型、使用终端内联 AI（`Ctrl+I`）、直接粘贴截图理解排障（`Ctrl+V`）的实操方法。

---

## 1. 终端进阶使用技巧 (Advanced Terminal Features)

### 1.1 弱网智能预测性本地回显 (Predictive Local Echo)
在跨国服务器、偏远地区或高延迟弱网环境下操作 SSH 时，击键与字符上屏往往存在数百毫秒的迟滞感。
- **技术原理**：Velowork 在 SSH 通道上全面启用了 `TCP_NODELAY`，同时引入了**预测性打字引擎**；
- **使用体验**：击键瞬间在本地预测显示，当远端服务器响应数据回包时进行毫秒级平滑校验与校准，彻底消除打字粘滞感。

### 1.2 终端行号对比度自适应与活动行高亮
- 可以在 **设置 -> 终端** 中勾选 **显示行号 (Show Line Numbers)**；
- **自适应对比度**：无论切换到暗黑还是亮白配色，行号均会动态计算最优视觉反差，杜绝行号不可见问题；
- **当前活动行高亮**：光标所在行行号会自动应用醒目的强调色高亮，在大屏多分屏排查日志时快速定位光标所在行。

### 1.3 终端内搜索与正则匹配 (`Cmd/Ctrl+F`)
- 按下 `Cmd+F` (macOS) / `Ctrl+F` (Linux/Windows) 唤起浮动搜索条；
- 支持普通文本搜索、正则表达式（Regex）搜索与大小写敏感匹配；
- 按 `Enter` / `Shift+Enter` 在命中结果之间快速平滑遍历跳转。

### 1.4 智能链接识别与外部代码编辑器直接联动
- 终端输出中的 HTTP/HTTPS 链接、IP 地址与文件路径会自动添加下划线与手型指针；
- **关联外部 IDE**：对于形如 `src/main.rs:142:18` 的报错输出，按住 `Ctrl` / `Cmd` 键并点击，Velowork 会自动呼出本机配置的编辑器（支持 **VS Code**、**Cursor**、**Zed**、**Sublime** 或 **Neovim**）并精准将光标定位至指定代码行和列。

## 2. AI 模型供应商接入与配置 (Configuring AI Models)

进入 **设置 -> AI 助手 (AI Settings)** 配置大模型服务：

### 2.1 支持的主流模型 Provider
- **DeepSeek**（官方 API 或硅基流动 / 兼容端点，推荐 `deepseek-chat` 或 `deepseek-reasoner`）；
- **Anthropic Claude**（`claude-3-5-sonnet` 等）；
- **OpenAI**（`gpt-4o`、`gpt-4o-mini` 等）；
- **Ollama（本地离线模型）**：无需连接外网，输入本地地址如 `http://localhost:11434`，天然保障企业代码与私网数据零泄露。

### 2.2 配置与连接测试步骤
1. 点击“添加模型”；
2. 输入模型标识名称、Base URL 与 Model ID；
3. **输入 API Key**：密钥将自动存入操作系统底层 Keyring（macOS Keychain / Linux Secret Service / Windows Credential Manager），本地配置文件不会明文保存 Key；
4. 点击 **测试连接 (Test Connection)**，系统会发送握手探测并在 1 秒内给出状态反馈。

## 3. 终端内联 AI 实战 (`TerminalInlineAi` - `Cmd/Ctrl+I`)

内联 AI 是 Velowork 最具生产力的特性之一。无需离开终端，无需手动复制粘贴命令行：

```text
[在终端敲代码时遇到不会写的复杂命令]
        ↓ 按下 Cmd+I / Ctrl+I
[终端光标处弹出 Command Palette 风格单行输入框]
        ↓ 输入自然语言需求："查找 /var/log 下大于 100M 的文件并按大小降序输出"
[AI 秒级解析并展开黄金比例建议卡片，给出精确 Shell 命令与解释]
        ↓ 按 Tab 或 Enter
[命令直接自动填入终端光标处，回车即执行！]
```

### 3.1 典型操作场景
- **自然语言直接转 CLI**：输入“统计 access.log 中请求状态码为 500 的接口及出现次数”，AI 精准生成 `awk '$9 ~ /500/ {print $7}' access.log | sort | uniq -c | sort -nr`；
- **解释晦涩脚本**：在内联框中输入 `解释一下上一行命令`，AI 逐段拆解参数语义；
- **报错自愈诊断**：上一条命令执行失败（如 `Permission denied` 或缺少依赖包），呼出内联 AI 输入 `为什么失败并给出修复命令`。

### 3.2 键盘流极速操作
- `Cmd+I` / `Ctrl+I`：唤起单行输入条；
- `Tab` 或 `Enter`：接受并上屏 AI 建议的命令；
- `Esc`：关闭浮窗并立即交还终端焦点。

## 4. 多模态 Vision 图像理解实战 (`Ctrl+V` 截图直接粘贴)

在复杂的运维与开发场景中，终端可能输出了长篇图形表格、或者系统弹出了图形报错窗口、或者网络监控图出现异常波形。纯文本很难完整描述。

Velowork 深度支持**多模态 Vision 协议**：

### 4.1 截图粘贴操作流程
1. 使用操作系统自带截图工具（如微信截图、Snipaste、macOS `Cmd+Shift+4`）截取屏幕报错区域；
2. 打开右侧 AI 助手面板（`Cmd+Shift+A` / `Ctrl+Shift+A`）；
3. **直接在 AI 输入框中按下 `Ctrl+V`**；
4. 截图将以异步 Base64 编码方式瞬间嵌入附件列表，并呈现等比缩略图胶囊；
5. 输入您的问题（如：“分析截图中 Docker 报错的原因，并给出解决方案”），回车发送；
6. 多模态大模型将同时综合分析视觉图像与上下文，给出精准修复指引。

### 4.2 附件卡片预览与管理
- 点击附件缩略图可唤起大图弹窗，支持等比缩放、系统默认图片查看器打开与快速删除；
- 内置严格的配额安全门禁，防止巨型图片引发内存阻塞。

## 5. 划选智能胶囊与历史会话 (Context & Chat History)

### 5.1 终端文本划选胶囊
- 在终端主视口中用鼠标选中任意一段报错日志或输出文本；
- 选区上方会自动浮现半透明的**智能胶囊工具栏**；
- 点击 **发送至 AI**，系统会自动将选中的输出作为上下文引用注入右侧 AI 会话，无需反复复制粘贴。

### 5.2 虚拟化无限历史回溯
- AI 对话消息基于 `gpui::list` 虚拟化与 SQLite 分页构建，即使累积数千条长对话也能实现零内存泄漏与丝滑上下滚动；
- 支持历史会话关键词全文检索，随时调取过往的排障记录。
