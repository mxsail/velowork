# 快捷指令与变量语法实操手册 (Quick Commands & Variable Syntax)

在日常运维与开发中，许多命令前缀固定但参数多变（如查询不同容器的日志、部署不同分支的代码、备份不同数据库）。Velowork 提供了**智能快捷指令库**与**动态变量占位符系统**，彻底消除在记事本中反复复制修改参数的机械劳动。

---

## 1. 快捷指令库结构与管理 (Command Library)

按快捷键 `Cmd+Shift+K` (macOS) / `Ctrl+Shift+K` (Linux/Windows) 可展开右侧的快捷指令面板：

### 1.1 新建与分组整理
- **创建文件夹**：点击指令栏顶部的“新建分类”图标（如 `Docker 容器管理`、`Nginx 运维`、`数据库备份`）；
- **新建指令**：点击“新建指令”按钮，进入编辑表单：
  - **指令名称**：直观说明用途（如 `查看指定容器最后 N 行日志`）；
  - **分类归属**：选择所在目录；
  - **指令内容**：支持单行命令或复杂的多行 Shell 脚本；
  - **说明与备注**：可选填入用法说明。

---

## 2. 动态参数占位符语法全解 (Placeholder Syntax)

Velowork 支持两种直观的变量语法：`{{变量名}}` 与 `${变量名}`。当指令包含占位符时，点击执行会自动弹出交互式模态参数填充窗口。

### 2.1 基础占位符
```bash
docker logs -f --tail 100 {{container_name}}
```
- 执行该指令时，界面会弹出输入框提示输入 `container_name`。

### 2.2 设定默认值 (Default Values)
在变量名后添加 `=` 或 `:` 即可指定默认填充值：
```bash
# 语法 1：{{变量名=默认值}}
docker logs -f --tail {{lines=200}} {{container_name}}

# 语法 2：${变量名:默认值}
mysqldump -u root -p${password:123456} ${database:production} > /backup/${database}.sql
```
- 弹窗打开时，输入框会自动预填设定的默认值，若无需修改直接回车即可执行，极大节省键入时间。

### 2.3 多变量联合替换
在一条长指令或多行脚本中，同一变量支持多次引用，输入一次自动全局替换：
```bash
tar -czvf {{app_name}}-{{version=v1.0.0}}.tar.gz /opt/{{app_name}} && \
scp {{app_name}}-{{version}}.tar.gz {{target_ip=192.168.1.100}}:/data/releases/
```

## 3. 运行交互与目标终端选择器 (Execution & Session Picker)

当您在指令列表中点击某条命令，或双击列表项时，将进入执行流：

### 3.1 动态模态填充与预览 (Parameter Modal)
1. 弹出居中的参数填充窗口；
2. 为每个识别到的占位符提供独立的输入框，并显示默认值；
3. **实时预览框 (Command Preview)**：
   - 随输入即时呈现替换完成后的最终完整命令，字号调整为清晰易读的标准 `ui_text_md`；
4. **操作分支**：
   - **立即运行 (Run)**：按 `Enter` 或点击运行，命令将被投递至目标终端并立即执行；
   - **仅复制 (Copy)**：点击复制按钮将解析后的命令写入系统剪贴板。

### 3.2 目标终端选择器 (Target Session Picker)
如果当前界面打开了多个分屏或多个服务器标签页，您可以精准指定将命令投递到哪一个终端：
- 在执行弹窗底部点击 **目标会话 (Target Session)** 下拉框；
- 系统列出当前所有活跃的终端窗格（支持自适应列宽、平滑滚动条与长名称智能截断）；
- 默认投递给当前处于激活状态的终端窗格。

## 4. 双面板协同：底栏极速条 vs 右侧指令树 (Dual Panel Workflow)

为了平衡“高频快速点击”与“深层分类归档”两种不同频次的场景，Velowork 提供了双面板分工：

### 4.1 底栏命令面板 (Bottom Dock - `Cmd/Ctrl+Shift+Y`)
- **适用场景**：日常每小时都要点按数次的最核心命令；
- **交互特点**：单行横向排布、极简胶囊按钮，不占用左右侧边栏空间，随时按 `Cmd+Shift+Y` 呼出/隐藏，单次点击直接投递。

### 4.2 右侧快捷指令面板 (Right Dock - `Cmd/Ctrl+Shift+K`)
- **适用场景**：系统化企业运维指令集（包含几十个目录、成百上千条指令）；
- **交互特点**：树状层级展开、全文搜索过滤、详细参数编辑与全量脚本查看。

---

## 5. 命令执行历史面板 (Command History Dock - `Cmd/Ctrl+Shift+H`)

Velowork 会自动持久化您在各个终端执行过的命令历史（可通过快捷键 `Cmd+Shift+H` / `Ctrl+Shift+H` 呼出）：

### 5.1 多行脚本紧凑规整展示
- 很多复杂的 `awk`、`sed`、多行 `for` 循环脚本在传统历史列表中会向下溢出、遮盖相邻列表；
- Velowork 会自动截取多行命令的首行进行规整单行呈现，并在行末增加弱化角标（如 `+2`、`+5`），清晰标识多行脚本体量。

### 5.2 悬浮 Tooltip 完整全览
- 将鼠标悬停在任意历史项上，即时弹出完整格式的多行代码悬浮卡片，附带执行时间戳与执行频次；
- 单击任意历史项即可快速将该命令回填至当前活动终端。
