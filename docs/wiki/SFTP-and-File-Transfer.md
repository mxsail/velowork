# 文件管理与高速传输实操手册 (SFTP & ZMODEM File Transfer)

Velowork 将图形化文件管理器与高速终端传输协议深度整合，提供**底栏 SFTP 双栏文件浏览器**与**终端原生 ZMODEM (`rz`/`sz`) 高速流式传输**两种工作方式。本手册详细介绍如何进行文件上传、下载、权限编辑、拖拽同步与大文件流控保障。

---

## 1. SFTP 双栏文件浏览器实操 (Dual-Pane SFTP Browser)

底栏 SFTP 浏览器可与中央终端工作区无缝协同，实现一边敲命令、一边直观监控与操作远程目录结构。

### 1.1 开启与聚焦
- 按下快捷键 `Cmd+Shift+F` (macOS) / `Ctrl+Shift+F` (Linux/Windows)，或点击应用底栏导航条的 **SFTP** 图标；
- 底栏自动平滑展开，左侧展示本地工作区目录，右侧展示当前活动 SSH 连接的远程服务器目录。

### 1.2 键盘快速导航与操作
SFTP 面板支持全键盘纯操作，大幅提升日常效率：
- `↑` / `↓`：在当前文件列表中上下切换光标；
- `Enter`：进入选中的文件夹；若为文本文件，则调用内置预览编辑器打开；
- `Backspace`：返回上一层父目录；
- `F2`：快速触发文件/文件夹重命名；
- `Delete`：删除选中文件（弹出安全二次确认弹窗）；
- `Tab`：在「本地窗格」与「远端窗格」之间自由切换焦点。

### 1.3 文件右键上下文菜单
右键点击任意远程文件或文件夹，可呼出功能菜单：
- **查看与编辑 (Edit/Preview)**：对于配置文件（如 `.conf`、`.yaml`、`.json`、`.sh`），无需下载到本地即可在内置编辑器中查看与轻量修改，保存时自动流式回写服务器；
- **文件属性 (Properties)**：查看精确文件字节大小、所属所有者（UID）与用户组（GID）、创建/修改时间戳，以及八进制权限掩码（如 `0644`、`0755`）并支持直接可视化修改文件权限；
- **下载 / 上传**：将选中项传输至对侧窗格对应目录；
- **复制绝对路径**：快速提取服务器绝对路径并复制到剪贴板，方便在终端命令行中粘贴。

## 2. 拖拽传输与任务管理器 (Drag & Drop & Transfer Manager)

### 2.1 拖拽上传与下载
- **从操作系统直接拖入**：
  从本地文件管理器（macOS Finder、Windows 资源管理器、Linux 文件管理器）直接按住文件或文件夹，拖拽到 Velowork 的终端主窗格或 SFTP 窗格中释放，系统将自动识别当前连接并触发上传流程。
- **双栏之间对拖**：
  在 SFTP 双栏中直接将本地文件拖拽到远程列表，或将远程文件拖入本地列表。

### 2.2 传输任务管理器 (Transfer Manager)
文件传输进行时，界面右下方会弹出非侵入式的传输胶囊面板：
- **实时指标**：查看当前传输速率（MB/s）、已传输字节数/总大小百分比及预计剩余时间；
- **多任务队列**：支持多文件并发队列传输与后台静默执行；
- **控制与重试**：点击暂停、取消或在遭遇瞬时网络故障后一键重试。

## 3. 终端原生 ZMODEM 传输实操 (`rz` / `sz`)

对于不希望频繁切换到 SFTP 界面的极客用户，Velowork 原生实现了硬化级 ZMODEM 协议。您只需在当前终端命令行内执行命令即可完成高速双向传输：

### 3.1 上传文件到服务器 (`rz`)
1. 在远程终端命令行中输入命令并回车：
   ```bash
   rz
   ```
2. Velowork 终端内核会自动侦测到 ZMODEM 的 `ZRINIT` 协议握手信号；
3. 本地操作系统会自动弹出原生文件选择对话框；
4. 选择要上传的文件后点击确认，数据即通过流式隧道高速传输至服务器当前所在目录。

### 3.2 从服务器下载文件 (`sz`)
1. 在远程终端命令行中输入待下载文件名并回车：
   ```bash
   sz filename.tar.gz
   ```
2. Velowork 捕获到发送信号后，自动弹出本地保存路径选择框；
3. 选定保存目录后即刻开启流式接收。

### 3.3 协议硬化与异常排空机制 (Hardened Protocol & Drain Loop)
传统终端在 ZMODEM 传输过程中一旦发生异常中断（如用户手动按 `Ctrl+C` 取消、网络断开），往往会导致大量二进制转义字符残留在终端屏幕上，甚至导致 PTY 彻底死锁。

Velowork 在协议底层做了多项硬化工程：
- **控制字符深度转义 (`ESCCTL`)**：防止网络传输中的控制序列干扰 PTY 流控；
- **0 字节空文件完整适配**：修复传统 ZMODEM 传输空文件时卡死的常见缺陷；
- **取消排空循环 (Cancellation Drain Loop)**：
  当用户在传输过程中点击取消时，系统会启动双向数据流排空循环，彻底消费并吸收管道中残留的脏数据包，保证取消后终端屏幕干干净净、无乱码回显、不卡死光标。

## 4. 常见问题排查 (Troubleshooting)

### Q1: 在终端执行 `rz` 或 `sz` 时提示 `command not found`？
**解答**：ZMODEM 依赖远端服务器安装了 `lrzsz` 工具包。请先在服务器上安装：
- Ubuntu / Debian: `sudo apt update && sudo apt install -y lrzsz`
- CentOS / RHEL: `sudo yum install -y lrzsz`
- Arch Linux: `sudo pacman -S lrzsz`

### Q2: SFTP 上传文件时提示 `Permission denied`？
**解答**：目标目录缺乏当前登录用户的写权限（例如非 root 用户尝试向 `/etc` 或 `/var/www` 写入）。请先在终端确认用户权限，或使用 `chown`/`chmod` 赋予目录相应写入权限。
