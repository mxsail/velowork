# 端口转发与隧道映射实操手册 (SSH Tunnels & Port Forwarding)

SSH 端口转发（Tunneling）是安全穿透防火墙、隔离子网以及在公网与私网之间架设加密通道的利器。Velowork 提供了**图形化 SSH 隧道管理器**（快捷键 `Cmd+Shift+U` / `Ctrl+Shift+U`），让您摆脱复杂的终端命令行参数，一键管理与监控各类端口映射。

---

## 1. 隧道三大模式原理与拓扑图解 (Tunnel Types)

| 模式 | 参数 | 核心流向 | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| **本地端口转发** | `-L` | 本地端口 -> SSH 远端服务器 -> 远端内网目标 | 本地直连云端私有 MySQL/Redis 数据库 |
| **远程端口转发** | `-R` | 远端服务器端口 -> SSH 远端 -> 本地机器端口 | 内网穿透：将本地开发的 Web 服务暴露给公网调试 |
| **动态 SOCKS5 代理** | `-D` | 本地端口 -> 全局加密流转 -> 经远端服务器出网 | 浏览器/工具整体代理上网、访问内网运维后台 |

---

## 2. 本地端口转发实操 (Local Forwarding `-L`)

### 2.1 典型业务场景
假设您有一台私有数据库服务器（IP 为 `192.168.1.50`，端口 `5432`），该机器未开放外网访问。您只能通过跳板机（公网 IP `1.2.3.4`）登录。现在您希望在本地电脑上使用 DBeaver 客户端直接连该数据库。

```text
[本地 DBeaver: 127.0.0.1:15432]
       ↓ (本地转发)
[本地 Velowork 绑定 15432 端口]
       ↓ (SSH 加密信道)
[跳板机 1.2.3.4:22]
       ↓ (内部局域网转发)
[内网数据库 192.168.1.50:5432]
```

### 2.2 界面配置步骤
1. 打开右侧 **隧道面板**（`Cmd+Shift+U` / `Ctrl+Shift+U`），点击“新建隧道”；
2. **隧道类型**：选择 **本地转发 (Local / -L)**；
3. **关联会话 (SSH Session)**：选取已配置好的跳板机会话（如 `生产跳板机-01`）；
4. **本地监听地址 (Local Bind)**：填 `127.0.0.1`；
5. **本地监听端口 (Local Port)**：填入未占用的本地端口（如 `15432`）；
6. **远程目标地址 (Remote Host)**：填 `192.168.1.50`；
7. **远程目标端口 (Remote Port)**：填 `5432`；
8. 点击保存，列表项旁会出现绿色的“启动”按钮，点击启动；
9. 启动成功后，在 DBeaver 中直接连接 `127.0.0.1:15432` 即可通畅访问远程数据库！

## 3. 远程端口转发实操 (Remote Forwarding `-R`)

### 3.1 典型业务场景
您在本地电脑开发了一个 Web 接口（监听在 `127.0.0.1:8080`），需要接收第三方服务（如微信支付 Webhook、GitHub Webhook）的回调通知，但您的电脑没有公网 IP。

```text
[外部 Webhook 请求]
       ↓
[公网服务器 1.2.3.4:9000]
       ↓ (SSH 反向转发信道)
[本地开发服务 127.0.0.1:8080]
```

### 3.2 界面配置步骤
1. 点击“新建隧道”，**隧道类型**选择 **远程转发 (Remote / -R)**；
2. **关联会话**：选取拥有公网 IP 的服务器会话；
3. **远程监听地址**：默认填 `0.0.0.0`（若需对外网全网开放）；
4. **远程监听端口**：填 `9000`；
5. **本地目标主机**：填 `127.0.0.1`；
6. **本地目标端口**：填 `8080`；
7. 点击保存并启动。此时访问 `http://1.2.3.4:9000` 将直接穿透至您本地运行的开发项目。

> 💡 **服务器配置避坑提示**：
> 若希望远程转发端口被外部互联网访问，需要在远程服务器的 `/etc/ssh/sshd_config` 中配置并重启 sshd：
> ```text
> GatewayPorts yes
> ```

## 4. 动态 SOCKS5 代理实操 (Dynamic Forwarding `-D`)

### 4.1 典型业务场景
通过远端服务器在本地动态架设一个加密 SOCKS5 代理网关，让浏览器可以安全访问远程服务器内网中的所有内部域名、GitLab、Jira 或私有 API。

### 4.2 界面配置步骤
1. 点击“新建隧道”，**隧道类型**选择 **动态转发 (Dynamic / -D)**；
2. **关联会话**：选取远程服务器会话；
3. **本地监听端口**：填入端口（如 `10808`）；
4. 点击保存并启动；
5. 在本地 Chrome 浏览器扩展（如 SwitchyOmega）或终端中设置 SOCKS5 代理为 `127.0.0.1:10808`，即刻安全通达远端网络环境。

## 5. 隧道生命周期与监控 (Lifecycle & Status)

- **状态指示灯**：
  - 🟢 **绿色**：隧道正常连通监听中；
  - 🔴 **红色**：连接中断或端口冲突；
  - ⚪ **灰色**：已停止；
- **随会话自动启动**：可在隧道属性中勾选“随 SSH 会话连接时自动开启”，实现一键联动；
- **异常重连机制**：当网络波动导致通道断开时，Velowork 后台进程会自动触发防抖重试，直到通道恢复就绪。
